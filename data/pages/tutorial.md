## 2. 单张卡片制作

:::info
本模板所有选项均使用 `||` 分隔，如：`选项A||选项B||选项C`；不需要加序号（如 `B.选项A`）
:::

### 2.1 选择题（单选、多选、判断）

- **Question** — 填写选择题的题干，任意文本格式
- **Options** — 填写选择题的各个选项，用 `||` 分隔。判断题如 `正确||错误`
- **Answer** — 填写答案；多选用 `ABC` 格式

![选择题示例](/data/media/tutorial/image2.jpg)

### 2.2 多小题（个案、病例分析、阅读理解）（仅 pro 版本）

- **Question** — 大题干和各个小题的题干，用 `##` 分隔。如：`大题干##小题1##小题2`
- **Options** — 每个小题的选项用 `||` 分隔，各小题用 `##` 分隔
- **Answer** — 每小题答案用 `##` 分隔。如：`C##ABC`

:::warning
题干、选项、答案的**数量必须一致**
:::

### 2.3 挖空题

- **Question** — 用 `[[……]]` 进行挖空，如：`这是[[挖空]]题目的[[示例]]`
- **ClozeText** — 复制 Question 字段的内容

:::info
支持嵌套挖空，如 `[[this is [[an]] apple]]`
:::

:::success
挖空支持：AnswerText、ClozeText、Analysis、Refrence 四个字段均支持挖空及嵌套挖空功能
:::

![挖空题示例](/data/media/tutorial/image3.jpg)

### 2.4 问答题

- **Question** — 填写问答题的题干
- **AnswerText** — 填写问答题的答案

:::success
当前版本 AnswerText 支持挖空了！
:::

![问答题示例](/data/media/tutorial/image4.jpg)

### 2.5 图遮挡题（仅 pro 版本）

- **Question** — 使用遮挡题制作工具绘制遮挡块，点击复制数据，将数据粘贴到此字段
- **ImageCloze** — 将截图或本地图片上传/复制到此字段

:::info
长截图效果更佳。若遮挡题制作工具打开没有工具栏，请缩小浏览器比例试试。
:::

![遮挡题工具](/data/media/tutorial/image5.jpg)
![遮挡题效果](/data/media/tutorial/image6.jpg)

### 2.6 挖空选择题（完形填空、选词填空）（仅 pro 版本）

- **Question** — 以 `$$` 或 `$$$` 开头，每个空用 `##` 表示。如：`$$这是一道完型填空题，需要填写##和##`
- **Options** — 每个小题的选项用 `||` 分隔，各小题用 `##` 分隔
- **Answer** — 每小题答案用 `##` 分隔

### 2.7 语句填空题（每个空用同一套答案）（仅 pro 版本）

- **Question** — 以 `$$` 或 `$$$` 开头，每个空用 `##` 表示
- **Options** — 各选项用 `||` 分隔，只用一套答案
- **Answer** — 答案格式与选择题一样，各空用 `##` 分隔

:::warning
题干、选项、答案的**数量必须一致**
:::

## 3. 表格工具批量制卡步骤

:::info
表格工具仅可用于批量制作导入**选择题、挖空题、问答题**
:::

### 操作流程

1. 打开 kikkua 表格文件，每行代表一题，选择题型
2. 根据颜色提示填写字段：**紫色**为必填项、**灰色**为禁填项，无色则选填

![表格概览](/data/media/tutorial/image7.jpg)

3. **导出为 CSV** — 导出前删除首行说明整行，依次点击 **文件 → 另存为 → 文件类型选择 CSV UTF-8 (逗号分隔)(*.csv) → 保存**

![导出CSV](/data/media/tutorial/image8.jpg)

### 导入 Anki（Windows 为例）

1. 打开 Anki，点击左上角 **文件 → 导入**，选择刚才的 CSV 文件
2. 字段识别区域：选择 **逗号** 分隔，允许 **HTML**
3. 导入选项：下拉选择使用 **kikkua模板** 和要保存的目标牌组
4. 字段匹配：右侧各个字段下拉选择字段，与左侧字段一一对应（注：标签字段选择空即可）
5. 点击右上角导入，完成导入

![导入Anki](/data/media/tutorial/image9.jpg)

### 表格操作注意事项

- 对于选择题、判断题**禁止填写 Options 字段**，请直接填写表格右侧的各个选项。Options 字段已设置公式，自动用符号 `||` 连接各个选项。选项上设置了答案选项自动绿色样式，您可根据样式核对答案是否设置正确

![选项样式](/data/media/tutorial/image10.jpg)

- 若选题型后没有自动出现每行间隔颜色，说明自动样式、颜色、公式没有应用到该行，您可双击本行的题型单元格，再按下回车键即可

:::info
对于表格中各种题型字段的填写要求，请查阅上方「单张卡片制作」中对应的卡片类型。
:::

## 4. 默认设置说明、永久修改

本 kikkua 模板的主题和卡片上显示的元素支持用户自定义，可点击右上角设置按钮 ⚙️ 进行控制。

![设置面板](/data/media/tutorial/image11.jpg)

### 永久更改默认配置

由于 Anki 的本地储存机制，安卓端无法永久保存设置，设置只对本次学习生效，且配置信息无法同步。若要永久更改默认的配置信息：

- **安卓端：** 点击右上角 `...` → 笔记类型 → 找到 kikkua 模板 → 点击编辑卡片 → 进入模板编辑页面
- **Windows 端：** 点击左上角 工具 → 管理笔记模板 → 找到 kikkua 模板 → 点击右侧 卡片 → 进入模板编辑页面

在模板编辑页面的**正面代码**中，最顶部可以看到配置信息，根据配置说明区域修改下方的参数，即可永久更改默认配置。

:::warning
请完整填写参数值，不要出现错误。**禁止对其他区域代码进行修改**，否则会导致模板无法使用。
:::

![模板编辑](/data/media/tutorial/image12.jpg)

:::info
部分设置应用后，下一张卡片才开始生效。
:::

## 6. 更新记录

本次更新与 2026/02/02，包含两部分内容：功能扩展和 Bug 修复。

### 6.1 功能扩展：挖空题应用范围扩展

**Analysis、Refrence、AnswerText** 三个字段均支持挖空题同款的挖空及嵌套挖空功能。

### 6.2 Bug 修复

- **6.2.1 多小题答案错误 bug** — 当有小题前面的字符相同时，答案会发生错误。已修复。
- **6.2.2 完型填空题内容显示 bug** — 完型填空题最后一个空后面的内容不会显示。已修复。
- **6.2.3 iOS 设置面板遮挡 bug** — 在 iOS 设备上，设置面板会滑到顶部，导致上方模态框被 Anki 导航栏覆盖。已修复。
- **6.2.4 完型填空多选失效 bug** — 在完型填空的多选模式下，只有最后一次点击的选项被记录。已修复。
