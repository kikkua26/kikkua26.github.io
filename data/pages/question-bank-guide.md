## 概述

题库编辑器是一个**表格化的题目管理工具**，支持选择题、挖空题、问答题等 kikkua 模板题型的批量制作。你可以手动添加题目、导入 CSV/Excel 文件、使用 AI 一键生成题目，最终导出为 CSV 或 APKG 牌组文件直接导入 Anki。

---

## 界面介绍

### 工具栏

| 按钮 | 功能 |
|---|---|
| **+ 添加行** | 新增一行空题目（右键可批量添加） |
| **文件导入** | 导入 CSV 或 Excel 文件（右键可下载模板） |
| **导出数据** | 导出为 CSV 或 Excel 文件 |
| **导出牌组** | 导出为 APKG 牌组文件，可直接导入 Anki |
| **AI 生成** | 使用 AI 根据知识内容自动生成题目 |
| **清空** | 清除所有数据 |

### 表格结构

每行代表一道题，列对应各个字段。**紫色** 为必填项，**灰色** 为该题型禁填项，无色为选填。

:::info
表格底部会自动保留一行空行，方便直接开始输入。数据会自动缓存到浏览器中。
:::

## 题型说明

### 选择题（单选、多选、判断）

- **Type** — 选择「单选题」「多选题」或「判断题」
- **Question** — 题干
- **OptionA ~ OptionF** — 各个选项（不需要的留空）
- **Answer** — 答案，如 `B`（单选）或 `AC`（多选），判断题填 `正确` 或 `错误`
- **Chapter / Analysis / Reference** — 选填

:::info
选项使用 `||` 分隔，不需要加序号。判断题选项自动设为「正确||错误」。
:::

### 挖空题

- **Type** — 选择「挖空题」
- **Question** — 用 `[[ ]]` 标记挖空位置，如 `这是[[挖空]]示例`
- **ClozeText** — 通常与 Question 内容相同
- **Answer** — 自动从挖空标记中提取

### 问答题

- **Type** — 选择「问答题」
- **Question** — 问题
- **AnswerText** — 标准答案

## 文件导入

### 支持格式

- **CSV** — UTF-8 编码的逗号分隔文件
- **Excel** — .xlsx / .xls 格式

### 导入步骤

1. 点击工具栏「文件导入」按钮（右键可下载空模板）
2. 选择文件
3. 系统自动识别表头并映射字段
4. 数据追加到表格末尾

:::info
导入时会自动跳过完全为空的行，也会自动识别并转换中英文题型名称。
:::

## AI 生成题目

### 配置 AI

1. 点击「✨ AI 生成」打开 AI 面板
2. 点击标题栏的「⚙️ AI 配置」按钮
3. 选择提供商（DeepSeek 或小米 MiMo）
4. 输入 API Key
5. 选择模型
6. 点击「🔗 测试连接」验证配置
7. 点击「保存设置」

:::info
没有 API Key？前往 [platform.deepseek.com](https://platform.deepseek.com) 注册获取。MiMo 请前往小米开放平台申请。
:::

### 生成模式

- **单题模式** — 从内容中选取最核心的知识点生成 1 道题
- **多题模式** — 覆盖所有知识点批量生成题目
- **整理模式** — 粘贴格式混乱的题目，AI 自动整理为标准格式

### 题型选择

- **选择题** — 自动生成单选/多选/判断题，含干扰选项
- **挖空题** — 自动识别关键术语并挖空
- **问答题** — 自动生成简答/论述题

### 解析风格

默认、通俗易懂、详细深入、简洁精炼、结合实例，5 种风格可选。

### 使用步骤

1. 选择题型、生成模式、解析风格
2. 可选填写章节名称
3. 在文本框中粘贴知识内容
4. 点击「生成」或「📋 复制提示词」

:::info
如果未配置 API Key，点击「生成」会自动弹出配置面板。

「📋 复制提示词」会将完整 prompt 复制到剪贴板，可粘贴到任意 AI 对话中使用，生成后回来通过「文件导入 → 粘贴文本」导入。
:::

## 导出功能

### 导出数据

点击「导出数据」弹出格式选择：

- **CSV kikkua 格式** — 适配 kikkua 模板的专用格式，选项合并为 `||` 分隔
- **CSV 标准格式** — 通用 CSV 格式，各选项单独一列
- **Excel (.xlsx)** — Excel 表格格式

### 导出 APKG 牌组

1. 点击「导出牌组」
2. 输入牌组名称
3. 可选勾选「根据章节生成子牌组」
4. 上传购买的 kikkua 牌组文件（.apkg）作为模板
5. 点击「导出」下载 .apkg 文件
6. 双击文件即可导入 Anki

:::warning
导出 APKG 需要先上传一个 kikkua 模板牌组文件，系统会从中提取卡片模板。如果还没有模板牌组，可前往购买。
:::

:::info
勾选「根据章节生成子牌组」后，Chapter 字段中用 `::` 分隔的内容会自动创建多层子牌组。例如 `中医基础::绪论::阴阳` 会创建「中医基础 → 绪论 → 阴阳」的层级结构。
:::

## 数据安全

- 数据**自动缓存**到浏览器本地存储
- 缓存不保证持久，请**定期导出 CSV 备份**
- 可随时通过「文件导入」恢复之前导出的数据
