## 概述

使用 kikkua 网站内置的**题库编辑器**和 **AI 生成功能**批量制作卡片。适合需要大量生成题目的场景 — 只需粘贴知识内容，AI 自动生成格式化的题目。

> 回到 [教程总览](/about?id=tutorial)

---

## 工具入口

访问 kikkua.online 的 [工具箱](/tools?tool=question-bank)，打开「题库编辑器」。

---

## 方式一：AI 自动生成题目

### 1. 配置 AI

1. 点击工具栏「✨ AI 生成」打开 AI 面板
2. 点击标题栏的「⚙️ AI 配置」按钮
3. 选择 AI 提供商（DeepSeek 或小米 MiMo）
4. 输入 API Key
5. 选择模型
6. 点击「🔗 测试连接」验证配置
7. 点击「保存设置」

:::info
没有 API Key？前往 [platform.deepseek.com](https://platform.deepseek.com) 注册获取。
:::

<!-- 插图待补充：AI 配置面板截图 -->

### 2. 选择生成参数

- **题型** — 选择题、挖空题、问答题
- **生成模式** — 单题模式（1 道）、多题模式（批量）、整理模式（格式化已有内容）
- **解析风格** — 默认、通俗易懂、详细深入、简洁精炼、结合实例
- **章节** — 可选，指定后所有题目归入该章节

### 3. 粘贴知识内容并生成

在文本框中粘贴知识点、课文段落、笔记等任何内容，点击「生成」。

AI 会自动将生成的题目导入到表格中。

### 4. 检查与调整

生成后在表格中检查题目，可逐题修改。确认无误后进入导出步骤。

---

## 方式二：复制提示词手动使用

如果没有 API Key，可以使用「📋 复制提示词」功能：

1. 配置好题型、模式、内容
2. 点击「📋 复制提示词」
3. 将提示词粘贴到任意 AI 对话中（如 DeepSeek 网页版）
4. 将 AI 返回的结果复制回来
5. 通过「文件导入 → 粘贴文本」导入到表格

## 导出到 Anki

### 导出 CSV

点击「导出数据」选择格式：

- **CSV kikkua 格式** — 适配 kikkua 模板，选项自动合并为 `||` 分隔
- **CSV 标准格式** — 通用 CSV
- **Excel (.xlsx)** — Excel 表格

然后按 [CSV 导入教程](/about?id=tutorial-csv-batch) 的步骤导入 Anki。

### 导出 APKG 牌组（推荐）

直接导出为 `.apkg` 文件，一步到位：

1. 点击「导出牌组」
2. 输入牌组名称
3. 可选勾选「根据章节生成子牌组」
4. 上传购买的 kikkua 牌组文件（.apkg）作为模板
5. 点击「导出」下载
6. 双击文件导入 Anki

:::warning
导出 APKG 需要先上传一个 kikkua 模板牌组文件，系统会从中提取卡片模板。
:::

:::info
勾选「根据章节生成子牌组」后，Chapter 字段中用 `::` 分隔的内容会自动创建多层子牌组。例如 `中医基础::绪论::阴阳` 会创建「中医基础 → 绪论 → 阴阳」的层级结构。
:::

## 数据安全

- 数据**自动缓存**到浏览器本地存储
- 缓存不保证持久，请**定期导出 CSV 备份**
- 可随时通过「文件导入」恢复之前导出的数据
