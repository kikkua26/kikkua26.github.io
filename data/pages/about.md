## 关于 kikkua

kikkua 是一个精选 Anki 牌组平台，致力于为学习者提供高质量的知识卡片。

### 我们的理念

- **精选内容** — 每副牌组都经过精心梳理，直击知识要点
- **先看后买** — 提供约 15% 的卡片免费预览，确保物有所值
- **专业模板** — 精心设计的 Anki 模板，兼具美感与效率

### 使用方式

1. 在[牌组列表](/decks)中浏览所有可用牌组
2. 点击「预览」进入牌组详情页
3. 点击「开始学习」免费预览约 15% 的卡片
4. 满意后通过购买链接获取完整牌组

> 学习之要，在于重复。温故知新，积微成著。

### 技术实现

本网站使用纯静态技术构建：

- **前端** — Vanilla JavaScript SPA，无框架依赖
- **托管** — GitHub Pages，全球 CDN 加速
- **数据** — 通过 GitHub API 管理内容
- **模板** — 兼容 Anki 笔记类型模板
